# Guide Utilisateur IBIG SECRETIS — Chapitre 04 : Réunions

> **Module** : Gestion des Réunions  
> **Profils concernés** : Secrétaire de Direction, Managers, Dirigeants  
> **Accès** : Menu > Réunions

---

## 1. Planifier une réunion

`Réunions > Nouvelle réunion`

### 1.1 Formulaire de planification

```
┌─────────────────────────────────────────────────────────────────┐
│  NOUVELLE RÉUNION                                               │
├─────────────────────────────────────────────────────────────────┤
│  Titre        : [_________________________________]             │
│  Type         : [▼ Réunion ordinaire ]                          │
│  Date         : [21/07/2026]  Heure début : [09:00]            │
│  Heure fin    : [11:00]  Durée estimée : 2h00                   │
│  Lieu         : [▼ Salle Émeraude   ] ou [En ligne]            │
│  Lien visio   : [https://meet.jit.si/secretis-...]             │
│  Organisateur : [Konan Adjoa — Secrétaire DG]                   │
│  Participants :                                                 │
│    [▼ Ajouter des participants...]                              │
│    ✓ M. Bah Oumar (DG) — Requis                                │
│    ✓ Mme Yao Alice (DAF) — Requise                             │
│    ~ M. Diallo Seydou (DRH) — Optionnel                        │
│                                                                 │
│  [  Enregistrer le brouillon  ]  [  Envoyer les convocations  ] │
└─────────────────────────────────────────────────────────────────┘
```

**Types de réunions disponibles :**

| Type | Usage |
|------|-------|
| Réunion ordinaire | Réunion de travail classique |
| Comité de direction | Réunion stratégique de direction |
| Conseil d'administration | Réunion du CA ou du Conseil |
| Réunion d'équipe | Point d'équipe opérationnel |
| Réunion de projet | Suivi de projet spécifique |
| Réunion extraordinaire | Urgence, convocation hors calendrier |
| Séminaire / Formation | Événement de formation ou séminaire |

## 2. Préparer l'ordre du jour

### 2.1 Ajouter des points à l'ordre du jour

Depuis la fiche de la réunion, onglet **Ordre du jour** :

1. Cliquez sur **+ Ajouter un point**
2. Saisissez :
   - **Titre du point** (ex : "Validation du budget Q3")
   - **Durée allouée** (ex : 20 minutes)
   - **Responsable** : qui présente ce point
   - **Documents joints** : pièces à consulter
   - **Type** : Information, Décision, Discussion, Divers
3. Réorganisez les points par **glisser-déposer**

**Exemple d'ordre du jour type :**

```
ORDRE DU JOUR — Comité de Direction
Lundi 21 juillet 2026, 09h00 — Salle Émeraude

  1. [10 min] Approbation du PV de la dernière réunion          (M. Bah)
  2. [20 min] Point sur les réalisations du mois de juin        (Mme Yao)
  3. [30 min] Validation du budget prévisionnel Q3 2026         (Mme Yao)
  4. [15 min] Point RH : recrutements en cours                  (M. Diallo)
  5. [20 min] Présentation du nouveau système ERP               (M. Konan)
  6. [10 min] Divers et questions                               (Tous)
  7. [05 min] Prochaine réunion et clôture                      (M. Bah)
```

### 2.2 Envoyer la convocation

Cliquez sur **Envoyer les convocations** pour notifier tous les participants. La convocation contient :
- Date, heure et lieu
- L'ordre du jour complet
- Les documents joints
- Un lien pour confirmer la participation

> **[ASTUCE]**  
> Envoyez les convocations au minimum 48 heures à l'avance pour les réunions ordinaires, et 15 jours pour les Conseils et Comités.

## 3. Conduire la réunion (mode en cours)

Le jour de la réunion, ouvrez la fiche et cliquez sur **Démarrer la réunion**.

SECRETIS passe en **mode réunion en cours** :

```
┌─────────────────────────────────────────────────────────────────┐
│  COMITÉ DE DIRECTION — En cours  ● LIVE   ⏱ 00:23:15           │
├─────────────────────────────────────────────────────────────────┤
│  POINT EN COURS : 2. Point réalisations juin   Restant: 07:00   │
│  ────────────────────────────────────────────────────────────── │
│  NOTES EN TEMPS RÉEL :                                          │
│  [___________________________________________________]          │
│  [___________________________________________________]          │
│                                                                 │
│  PRÉSENTS : ✓ M. Bah  ✓ Mme Yao  ✗ M. Diallo (absent excusé)  │
│                                                                 │
│  [◄ Point précédent]  [Point suivant ►]  [⏹ Terminer]          │
└─────────────────────────────────────────────────────────────────┘
```

**Fonctionnalités du mode en cours :**

- **Minuteur par point** : chronomètre le temps alloué à chaque point
- **Émargement en temps réel** : marquez la présence/absence des participants
- **Prise de notes** : zone de saisie rapide synchronisée pour le secrétaire
- **Enregistrement des décisions** : bouton **+ Décision** pour capturer les résolutions
- **Actions à suivre** : bouton **+ Action** pour enregistrer les tâches issues de la réunion

## 4. Rédiger le compte rendu avec l'éditeur TipTap

Après la réunion, accédez à l'onglet **Compte rendu** de la fiche réunion.

L'éditeur TipTap riche est disponible avec les fonctionnalités suivantes :

| Fonctionnalité | Description |
|----------------|-------------|
| **Formatage** | Gras, italique, souligné, titre H1/H2/H3 |
| **Listes** | Listes numérotées et à puces |
| **Tableaux** | Insertion de tableaux dynamiques |
| **Mentions** | Mentionner un utilisateur avec `@nom` |
| **Décisions** | Bloc structuré pour les décisions |
| **Actions** | Bloc structuré avec assignation et échéance |
| **Import notes** | Importer automatiquement les notes prises pendant la réunion |

**Structure recommandée du compte rendu :**

```
# PROCÈS-VERBAL DE RÉUNION
## Comité de Direction — 21 juillet 2026

**Date :** 21 juillet 2026 à 09h00
**Lieu :** Salle Émeraude — Siège social
**Participants :** M. Bah Oumar (DG), Mme Yao Alice (DAF)
**Absent(s) excusé(s) :** M. Diallo Seydou (DRH)
**Secrétaire de séance :** Mme Konan Adjoa

---

## 1. Approbation du PV précédent
Le PV de la réunion du 7 juillet 2026 est approuvé à l'unanimité.

## 2. Point sur les réalisations de juin
[Résumé des discussions...]

### Décisions
> DÉCISION 1 : Le rapport de juin est validé et transmis à la direction.
> Votants : Pour (2), Contre (0), Abstention (0)

## 3. [...]
```

## 5. Utiliser SARA pour extraire les décisions

[SARA] Après avoir saisi ou importé les notes brutes de réunion, SARA peut vous aider :

1. Cliquez sur **[SARA] Analyser les notes**
2. SARA lit le contenu et extrait automatiquement :
   - Les **décisions** prises
   - Les **actions** à réaliser avec les responsables cités
   - Les **points renvoyés** à une prochaine réunion
3. Validez, modifiez si besoin, et confirmez l'intégration dans le compte rendu

> **[ASTUCE]**  
> Vous pouvez également demander à SARA de rédiger un résumé exécutif de 5 lignes pour le Directeur Général.

## 6. Valider et signer le compte rendu

### 6.1 Workflow de validation

Le compte rendu suit un cycle de validation :

```
  BROUILLON ──► EN VALIDATION ──► VALIDÉ ──► SIGNÉ ──► PUBLIÉ
```

1. **Brouillon** : le secrétaire rédige le compte rendu
2. **En validation** : le compte rendu est soumis aux participants pour relecture
3. **Validé** : les participants approuvent le contenu
4. **Signé** : le responsable de séance signe électroniquement
5. **Publié** : le compte rendu est accessible à tous les participants

### 6.2 Soumettre pour validation

1. Cliquez sur **Soumettre pour validation**
2. Sélectionnez les **validateurs** (président de séance, participants principaux)
3. Définissez une **date limite** de validation
4. Cliquez sur **Envoyer**

Chaque validateur reçoit une notification et peut commenter ou approuver depuis la fiche.

### 6.3 Signature électronique

Lorsque le statut passe à **Validé**, le président de séance reçoit une demande de signature :
1. Il clique sur **Signer le compte rendu**
2. Il confirme son identité (mot de passe ou code OTP)
3. La signature électronique est apposée avec l'horodatage

## 7. Suivre les décisions et les transformer en tâches

`Réunions > Décisions`

### 7.1 Tableau de suivi des décisions

```
┌──────────┬─────────────────────────────┬──────────┬──────────┬──────────┐
│  Réf.    │  Décision                   │  Resp.   │  Échéance│  Statut  │
├──────────┼─────────────────────────────┼──────────┼──────────┼──────────┤
│ DEC-042  │ Valider le budget Q3        │ Mme Yao  │ 31/07/26 │ ✓ Réalisé│
│ DEC-043  │ Recruter 2 techniciens      │ M. Diallo│ 15/08/26 │ En cours │
│ DEC-044  │ Lancer le projet ERP Phase 2│ M. Konan │ 01/09/26 │ En attente│
└──────────┴─────────────────────────────┴──────────┴──────────┴──────────┘
```

### 7.2 Transformer une décision en tâche

1. Cliquez sur la décision
2. Cliquez sur **Créer une tâche**
3. La tâche est pré-remplie avec le titre, le responsable et l'échéance de la décision
4. Ajustez les détails si nécessaire
5. Cliquez sur **Créer la tâche**

La tâche est automatiquement liée à la décision et apparaît dans le module Tâches.

---

## 8. Exporter le compte rendu en PDF

1. Ouvrez la fiche de la réunion, onglet **Compte rendu**
2. Cliquez sur **Exporter en PDF**
3. Choisissez le **modèle de mise en page** (Standard, Officiel avec en-tête, etc.)
4. Cochez les sections à inclure :
   - [✓] Page de garde
   - [✓] Participants et émargement
   - [✓] Ordre du jour
   - [✓] Corps du compte rendu
   - [✓] Tableau des décisions et actions
   - [ ] Annexes (documents joints)
5. Cliquez sur **Télécharger le PDF**

> **[i] Information**  
> Le PDF généré inclut automatiquement l'en-tête de l'organisation (logo, nom), un pied de page avec numérotation et la mention de confidentialité définie.
