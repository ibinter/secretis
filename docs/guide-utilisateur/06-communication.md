# Guide Utilisateur IBIG SECRETIS — Chapitre 06 : Communication

> **Module** : Communication & Annuaire  
> **Profils concernés** : Tous les utilisateurs  
> **Accès** : Menu > Communication | Menu > Annuaire

---

## 1. Envoyer un message direct

`Communication > Messages > Nouveau message`

### 1.1 Messagerie interne

La messagerie interne de SECRETIS permet d'échanger avec tous les collaborateurs de l'organisation.

1. Cliquez sur **+ Nouveau message** ou sur le nom d'un utilisateur
2. Dans le champ **Destinataire**, recherchez et sélectionnez le collègue
3. Rédigez votre message dans la zone de texte
4. Ajoutez des pièces jointes si nécessaire (📎)
5. Appuyez sur **Entrée** ou cliquez sur **Envoyer**

**Fonctionnalités de la messagerie :**

| Fonctionnalité | Description |
|----------------|-------------|
| Accusé de lecture | Indication `Lu` avec horodatage |
| Réponse rapide | Répondre à un message spécifique dans la conversation |
| Réactions | Réagir avec des emojis (👍 ✅ 🙏) |
| Épingler | Épingler un message important dans la conversation |
| Recherche | Rechercher dans l'historique de la conversation |
| Partage de document | Partager un document de la GED directement |

> **[!] Attention**  
> La messagerie SECRETIS est une messagerie professionnelle interne. Elle est enregistrée dans le journal d'audit et peut être consultée par les administrateurs.

## 2. Créer un groupe de discussion

1. Dans **Communication > Messages**, cliquez sur **+ Nouveau groupe**
2. Renseignez :
   - **Nom du groupe** (ex : "Équipe Communication")
   - **Description** (optionnel)
   - **Membres** : ajoutez les participants (minimum 3 personnes pour un groupe)
   - **Administrateurs du groupe** : désignez les modérateurs
3. Cliquez sur **Créer le groupe**

**Gestion du groupe :**

- **Ajouter un membre** : `⚙️ Paramètres > Membres > Ajouter`
- **Supprimer un membre** : `⚙️ Paramètres > Membres > Retirer`
- **Muter le groupe** : désactiver les notifications pour ce groupe
- **Archiver le groupe** : fermer le groupe sans supprimer l'historique

## 3. Rédiger et diffuser une circulaire

`Communication > Circulaires > Nouvelle circulaire`

La circulaire est une communication officielle avec suivi des accusés de réception.

### 3.1 Formulaire de rédaction

```
┌─────────────────────────────────────────────────────────────────┐
│  NOUVELLE CIRCULAIRE                                            │
├─────────────────────────────────────────────────────────────────┤
│  Référence   : [CIRC-2026-0018]  (auto)                        │
│  Objet       : [_________________________________]              │
│  Catégorie   : [▼ Administrative ]                              │
│  Priorité    : (●) Normale  ( ) Urgente                         │
│  Destinataires :                                                │
│    [✓] Toute l'organisation                                     │
│    [ ] Département spécifique : [▼ Sélectionner ]               │
│    [ ] Utilisateurs sélectionnés                                │
│                                                                 │
│  Contenu :                                                      │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ [B] [I] [U] [≡] [≡] [📎]                               │   │
│  │                                                         │   │
│  │ [Zone de rédaction rich text]                           │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  Pièces jointes : [📎 Ajouter]                                  │
│  Date d'envoi   : [● Immédiatement  ○ Planifiée le : ______]   │
│  Accusé de réc. : [✓] Obligatoire                               │
│                                                                 │
│  [  Prévisualiser  ]  [  Envoyer  ]                             │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 Catégories de circulaires

| Catégorie | Exemples d'usage |
|-----------|-----------------|
| Administrative | Changement de procédure, rappel règlement |
| RH | Annonce recrutement, congés collectifs |
| Informatique | Maintenance système, nouveaux outils |
| Direction | Message du DG, orientations stratégiques |
| Urgente | Information critique, alerte sécurité |

## 4. Suivre les accusés de réception

Après l'envoi d'une circulaire, consultez le suivi :

`Communication > Circulaires > [Nom de la circulaire] > Suivi`

```

│  Taux de lecture : 18/25 (72%)  ████████████████░░░░           │

│  Destinataire         │  Statut        │  Date de lecture        │
```

## 5. Gérer l'annuaire (interne et externe)

`Communication > Annuaire`

### 5.1 Annuaire interne

L'annuaire interne est alimenté automatiquement par les fiches utilisateurs.

**Informations disponibles par collaborateur :**
- Photo de profil
- Nom complet et poste
- Département et service
- Email interne et téléphone
- Manager direct
- Disponibilité (selon agenda partagé)

**Recherche dans l'annuaire :**
- Par nom, prénom, ou email
- Par département ou service
- Par poste ou fonction

### 5.2 Annuaire externe (contacts)

L'annuaire externe regroupe les contacts hors de l'organisation (partenaires, fournisseurs, autorités, etc.).

1. Cliquez sur **+ Nouveau contact**
2. Renseignez les informations :
   - Prénom, Nom
   - Organisation / Société
   - Poste / Fonction
   - Email, Téléphone(s)
   - Adresse
   - Catégorie (Fournisseur, Client, Partenaire, Autorité, etc.)
   - Notes

## 6. Importer des contacts depuis Excel

`Communication > Annuaire > Importer`

### 6.1 Préparer le fichier Excel

Téléchargez le **modèle d'importation** fourni par SECRETIS :

| Colonne | Obligatoire | Exemple |
|---------|-------------|---------|
| Prénom | ✓ | Marie |
| Nom | ✓ | KONAN |
| Email | ✓ | m.konan@client.ci |
| Organisation | | IBIG Technologies |
| Poste | | Directeur Commercial |
| Téléphone | | +225 07 XX XX XX |
| Catégorie | | Client |
| Notes | | Relance prévue août 2026 |

### 6.2 Importer le fichier

1. Cliquez sur **Importer des contacts**
2. Sélectionnez votre fichier Excel (.xlsx)
3. SECRETIS affiche un aperçu des données détectées
4. Vérifiez la correspondance des colonnes (mapping automatique)
5. Sélectionnez l'action pour les doublons : Ignorer, Mettre à jour, ou Demander
6. Cliquez sur **Lancer l'importation**
7. Un rapport d'importation indique le nombre de contacts créés, mis à jour et ignorés

## 7. Publier une annonce sur le tableau d'affichage

`Communication > Tableau d'affichage > Nouvelle annonce`

Le tableau d'affichage est un espace de communication informelle accessible à tous.

### 7.1 Créer une annonce

```
┌─────────────────────────────────────────────────────────────────┐
│  NOUVELLE ANNONCE                                               │
├─────────────────────────────────────────────────────────────────┤
│  Titre    : [_________________________________]                  │
│  Catégorie: [▼ Événement      ]                                  │
│  Contenu  : [Zone de texte enrichi...]                          │
│  Image    : [📷 Ajouter une image]                              │
│  Épingler : [ ] Épingler en tête du tableau                     │
│  Visible  : (●) Toute l'organisation  ( ) Département           │
│  Expire le: [__/__/____]  (laisser vide = pas d'expiration)     │
│                                                                 │
│  [  Publier  ]  [  Prévisualiser  ]                             │
└─────────────────────────────────────────────────────────────────┘
```

**Catégories du tableau d'affichage :**

| Catégorie | Exemples |
|-----------|----------|
| Événement | Journée portes ouvertes, fête d'entreprise |
| Recrutement | Offre de poste interne |
| Information | Changement d'horaires, travaux |
| Félicitations | Promotion, naissance, anniversaire |
| Perdu/Trouvé | Objets dans les locaux |
| Sondage | Vote, choix de date d'événement |

> **[ASTUCE]**  
> Les annonces peuvent être "Épinglées" pour rester en tête du tableau pendant une durée définie. Idéal pour les informations importantes comme les congés collectifs ou les événements à venir.
