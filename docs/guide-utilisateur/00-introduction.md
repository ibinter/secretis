## Bienvenue sur IBIG SECRETIS

IBIG SECRETIS est la plateforme de gestion administrative intelligente conçue pour les organisations africaines et francophones qui souhaitent digitaliser, fluidifier et optimiser l'ensemble de leurs processus administratifs.

Qu'il s'agisse de gérer le courrier entrant et sortant, de planifier des réunions, de coordonner les tâches d'équipe, d'accueillir les visiteurs ou de produire des rapports de direction, SECRETIS centralise tous ces flux dans un environnement sécurisé, accessible depuis n'importe quel appareil.

SARA, votre assistante IA intégrée, vous accompagne à chaque étape : elle suggère des créneaux, extrait les décisions de vos réunions, rédige des synthèses et vous alerte en temps réel sur les priorités du jour.

Ce guide vous accompagne pas à pas dans la prise en main et la maîtrise complète de SECRETIS.

## Glossaire des termes SECRETIS

| Terme | Définition |
|-------|-----------|
| **SARA** | Secrétaire Artificielle Responsive et Autonome — l'assistante IA intégrée à SECRETIS |
| **Organisation** | L'entité (entreprise, administration, ONG) qui utilise SECRETIS. Correspond à un tenant isolé |
| **Tenant** | Instance dédiée et isolée de SECRETIS attribuée à une organisation |
| **Module** | Fonctionnalité autonome de SECRETIS (Agenda, Courrier, Réunions, etc.) activable selon l'abonnement |
| **Rôle** | Ensemble de permissions attribué à un utilisateur (Admin, Manager, Agent, Viewer) |
| **Permission** | Droit d'accès granulaire à une action ou une ressource (ex : courrier.create) |
| **GED** | Gestion Électronique des Documents — module de stockage et d'organisation des fichiers |
| **Workflow** | Séquence d'états et d'actions définissant le cycle de vie d'un objet (courrier, demande de congé) |
| **Compte rendu** | Document officiel résumant les décisions et actions d'une réunion |
| **Ordre du jour** | Liste structurée des points à traiter lors d'une réunion |
| **Kanban** | Vue visuelle des tâches organisées en colonnes (À faire, En cours, Terminé) |
| **Gantt** | Diagramme temporel représentant la planification et l'avancement des tâches d'un projet |
| **Circulaire** | Communication officielle diffusée à un groupe d'utilisateurs avec accusé de réception |
| **Badge visiteur** | Document imprimable ou numérique identifiant un visiteur lors de sa présence dans les locaux |
| **PWA** | Progressive Web App — version mobile de SECRETIS installable sur smartphone sans app store |
| **ICS** | Format de fichier standard pour l'échange de calendriers (compatible Google Calendar, Outlook) |
| **Audit Trail** | Journal horodaté et inaltérable de toutes les actions effectuées dans le système |
| **Confidentialité** | Niveau de restriction d'accès à un document (Public, Interne, Confidentiel, Secret) |
| **Récurrence** | Répétition automatique d'un événement selon une règle (quotidien, hebdomadaire, mensuel) |
| **Intégration** | Connexion de SECRETIS à un service externe (SMTP, WhatsApp, API IA) |

## Conventions utilisées dans ce guide

### Icônes et symboles

| Symbole | Signification |
|---------|--------------|
| `[i]` | Information complémentaire utile |
| `[!]` | Point d'attention important à ne pas négliger |
| `[DANGER]` | Action irréversible — procéder avec précaution |
| `[SARA]` | Fonctionnalité assistée par l'IA SARA |
| `[ADMIN]` | Action réservée aux administrateurs |
| `[ASTUCE]` | Conseil pour gagner du temps ou optimiser l'usage |
| `[RACCOURCI]` | Raccourci clavier disponible |

### Alertes

> **[i] Information**  
> Apporte un contexte supplémentaire ou une précision technique.

> **[!] Attention**  
> Point critique à lire avant d'effectuer une action.

> **[DANGER] Action irréversible**  
> Cette action ne peut pas être annulée. Vérifiez avant de confirmer.

### Formatage des procédures

Les étapes numérotées suivent ce format :
1. **Action** — description de ce qu'il faut faire
2. **Résultat attendu** — ce qui doit se passer à l'écran

Les chemins de navigation sont indiqués ainsi : `Menu > Sous-menu > Page`

Les champs de formulaire sont indiqués en **gras** : renseignez le champ **Objet**.

Les valeurs à saisir sont indiquées en `code` : saisissez `CONF-2026`.
