## Méthodologie de traduction

### Langues FR et EN
- **Méthode** : Traduction professionnelle native par l'équipe IBIG Soft
- **Revue** : Relecture native par locuteurs francophones et anglophones
- **Qualité** : Ton professionnel, terminologie ERP standardisée
- **Cohérence** : Tableau de glossaire maintenu pour les termes métier

### Arabe (AR)
- **Dialecte** : Arabe moderne standard (fusha) — compréhensible dans tout le Maghreb et le Moyen-Orient
- **Méthode** : Traduction initiale assistée par modèle de langue, revue manuelle planifiée
- **RTL** : Direction gérée par CSS (`dir="rtl"` sur `<html>`) — pas d'encodage dans les traductions
- **Validation** : Revue par locuteur natif arabe requise avant mise en production

### Portugais (PT)
- **Variante** : Portugais du Portugal (proche des variantes africaines : Angola, Mozambique, Cap-Vert, São Tomé, Guinée-Bissau)
- **Différences** : Quelques adaptations lexicales prévues pour pt-AO (Angola) et pt-MZ (Mozambique)
- **Méthode** : Traduction initiale assistée, revue planifiée
- **Fichiers existants** : pt-BR.json (mis à jour), pt-MZ.json, pt-ST.json (variantes à compléter)

### Swahili (SW)
- **Standard** : Kiswahili standard (Kenya, Tanzanie, Ouganda, RDC)
- **Orthographe** : Conforme à la norme BAKITA (Baraza la Kiswahili la Taifa)
- **Méthode** : Traduction assistée, validation communautaire prévue
- **Statut** : Traduction partielle couvrant les fonctions essentielles

### Haoussa (HA)
- **Transcription** : Alphabet latin (Boko) — standard officiel Nigéria et Niger
- **Dialecte** : Haoussa kano (dialecte de référence, le plus largement compris)
- **Méthode** : Traduction assistée, validation par locuteur natif requise
- **Statut** : Traduction partielle couvrant les fonctions essentielles

## Recommandations pour les langues futures

### Bambara (Bamanankan)
- **Locuteurs** : ~15 millions (Mali, Guinée, Côte d'Ivoire, Burkina Faso)
- **Alphabet** : Latin + caractères N'Ko optionnel
- **Priorité** : Haute pour le marché mali/guinéen
- **Complexité** : Faible — pas de RTL, alphabet latin

### Wolof
- **Locuteurs** : ~12 millions (Sénégal, Gambie, Mauritanie)
- **Alphabet** : Latin
- **Priorité** : Haute pour le marché sénégalais
- **Complexité** : Faible

### Amharique (Amharic)
- **Locuteurs** : ~25 millions natifs (Éthiopie)
- **Alphabet** : Guèze (Ethiopic) — écriture unique
- **Priorité** : Moyenne — marché éthiopien émergent
- **Complexité** : Haute — nécessite polices Noto Ethiopic, render engine spécifique

### Tigrigna
- **Locuteurs** : ~9 millions (Érythrée, Éthiopie nord)
- **Alphabet** : Guèze (même que Amharique)
- **Priorité** : Faible

### Yoruba et Igbo
- **Locuteurs** : 30-40M chacun (Nigéria)
- **Alphabet** : Latin avec diacritiques
- **Priorité** : Moyenne après complétion Haoussa
- **Complexité** : Faible-moyenne (gestion diacritiques)
